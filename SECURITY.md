# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities in a public issue. Use the
private vulnerability reporting feature on the
[GitHub security page](https://github.com/symbioticode/mif-core/security) when
it is available, or contact the repository owner through GitHub.

Include the affected version, a concise description, reproduction steps, and
any proposed mitigation. Please avoid including credentials, private market
data, or other sensitive material in the report.

This project is an offline qualification layer. It does not fetch market data
or execute trades, but integrations may still handle sensitive data and should
be reviewed accordingly.

## Supported versions

Only the latest code on `main` is actively maintained while the project is in
development (`0.1.0.dev1`).
